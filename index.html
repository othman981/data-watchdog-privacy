Privacy Policy: Watchdog Privacy Monitor

Last updated: 26 October 2026

Watchdog Privacy Monitor is a Chrome extension that shows you what data each website tries to access and lets you allow, block or spoof it per site.

The short version

Watchdog does not collect, transmit, sell or share your personal information. Everything it records stays on your own computer. There is no account, no server, no analytics and no telemetry.

What is stored, and where

All of the following is stored locally on your device using Chrome's chrome.storage.local, and never leaves it:

  • Your settings for each site: which of the 22 categories you have set to Allow, Ask, Block, Spoof, Noise or Protect for each website, and any spoofing profile you have chosen (for example a city for location, or a GPU string for WebGL).
  • Counters for each site: how many times each category was allowed or blocked on a site. These are counts only, capped at 300 sites, with the least recently used dropped beyond that.
  • A short activity log for each tab: the recent API calls a page made, held in memory only, capped at 80 entries per tab and 25 tabs, and discarded when the tab is closed or navigates. It is never written to disk.

You can view, export, edit and delete all of it at any time from the extension's options page. Uninstalling the extension removes it.

The one network request

Watchdog makes exactly one outbound request, and only when you explicitly click for it:

"Check my public IP" in the popup sends a request to https://api.ipify.org, a public IP echo service, and displays the IP it returns. It is not sent anywhere else and is not stored. It exists so you can see what a website would see. That is useful when checking WebRTC leak protection.

If you never click that button, the extension makes no network requests at all. Fonts are loaded from your own system rather than a CDN, and the extension contains no remote code.

Your use of api.ipify.org is subject to that service's own terms; it necessarily observes your IP address in order to report it back to you.

What Watchdog Privacy Monitor can technically see

To do its job the extension has access to the pages you visit. That is what lets it observe and control what those pages request. It uses that access only to apply your settings and to show you the activity for the tab you are currently looking at. None of it is recorded beyond the local storage described above, and none of it is transmitted.
